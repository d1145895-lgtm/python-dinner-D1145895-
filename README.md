## 3. 問題回答

### 問題一：為什麼 4 要先轉成數字，才能用於本題的分攤計算？
因為在 Python 裡面，原本輸入的 4 是字串也就是文字，不是真的數字 4。電腦只把它當成一個文字符號，不知道這代表數量，所以拿總金額去除以文字的時候，Python 會直接報錯給你看。一定要先用 int 把它轉成整數，才能拿來做除法計算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
如果先扣折價券再算服務費，第一組的應付總額會變成 1,210 元。

算法會變這樣：
* 先扣折價券：1200 - 100 = 1100 元
* 用剩下的 1100 元算 10% 服務費：1100 × 0.10 = 110 元
* 最後應付總額：1100 + 110 = 1210 元

跟原本算出來 1,220 元差了 10 塊錢，原因是計算服務費的基數不一樣。題目規定要用原始餐費 1,200 元去算服務費，所以服務費是 120 元；但如果先扣掉 100 元折價券，算服務費的基數就縮水變成 1,100 元，連帶讓服務費少了 10 元。
