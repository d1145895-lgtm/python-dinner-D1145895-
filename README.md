## 3. 問題回答

一、為什麼4要先轉成數字，才能用於本題的分攤計算？
因為原本輸入的4是字串(文字)，不是真的數字4。所以拿總金額去除以文字的話Python會直接報錯。一定要先用int轉成整數才能拿來做除法計算。

二、如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
A:1220元

算試:
先扣折價券 1200-100=1100
用剩下的1100元算10%服務費 1100×0.10=110
最後應付總額 1100+110=1210

跟原本算出來1220元差了10塊錢，主因是服務費的不同。題目規定要用原始餐費1,200元去算，所以服務費是120元；但如果先扣掉100元折價券，算服務費的基數就變成1,100元，服務費少了10元。
